# 方法论：六维、原型、象限、矩阵与地图

本文件说明 `scripts/metrics.py` / `scripts/archetypes.py` / `scripts/derive.py` 的计算口径，供复核与复现。

## 一、从观测事实到原始特征

窗口年数 `years = trading_days / 243`（A 股一年按 243 个交易日折算，与波动率年化系数一致）。

| 原始特征 | 计算 |
|---|---|
| `spikes_per_year` | 异动事件数 ÷ years |
| `limit_up_per_year` | 其中 `limit_up=true` 的数 ÷ years |
| `max_streak` | 各事件 `streak` 的最大值（**停牌会断板**，见下） |
| `selected_days_per_year` | (异动日 ∪ **全部**龙虎榜日) 去重后的天数 ÷ years → 报告里的「被选中次数/年」 |
| `avg_next_day_pct` | 有 `next_day_pct` 的事件均值 |
| `next_day_win_rate_pct` | `next_day_pct > 0` 的事件占比 |
| `bury_rate_pct` | `drawdown_nd_pct ≤ dump_drawdown_pct` 的事件占比 |
| `severe_drop_rate_pct` | `next_day_pct ≤ -5%` 的事件占比 |
| `lhb_per_year` | **净额达标**的龙虎榜记录数 ÷ years（见 `lhb_net_min_cny`） |
| `lhb_net_mean_cny` | 净额达标记录的净额均值 |
| `capacity` | 顶层 `capacity_metric` 对应的值 |
| `volatility_ann_pct` | 日收益标准差 × √243 |
| `ret_60d_pct` | 前复权序列 60 日区间涨跌幅 |

**缺证据一律 None**：某个特征没有样本（例如无任何异动事件）时为 None，不填 0。

### 连板的两个口径细节

1. **停牌断板**：连板按「相邻交易日」判定，并对照交易日历。若相邻两根 K 线在日历上不相邻（中间夹着停牌或缺失交易日），连板链清零。否则会把「停牌前后各若干板」拼成一条长链，系统性高估最高连板。
2. **`lhb_net_min_cny` 只筛 D5**：净额门槛用于「资金关注度」维度（`lhb_per_year`、`lhb_net_mean_cny`）；「被选中次数/年」仍按**全部**龙虎榜上榜日计——上榜本身就是被资金选中，与净额大小是两件事。门槛默认 0（不过滤）。

## 二、池内百分位归一化

每个原始特征在其**非空样本**内做百分位排名（并列取平均秩）：

```
percentile = (小于它的个数 + (等于它的个数 − 1)/2) / (样本数 − 1) × 100
```

样本数为 1 时返回 **50.0** —— 单点无法定序，不假装它在两端。

六维由原始特征的百分位加权合成（权重在 `metrics.score_dimensions` 内固定，是口径的一部分）：

| 维度 | 合成 |
|---|---|
| D1 | 0.40 × spikes/年 + 0.35 × 涨停/年 + 0.25 × 最高连板 |
| D2 | 0.60 × 次日涨跌幅 + 0.40 × 次日胜率 |
| D3 | 0.75 × 埋人率 + 0.25 × 次日大跌占比 |
| D4 | 容量分位（单变量） |
| D5 | 0.60 × 龙虎榜/年 + 0.40 × 龙虎榜净额均值 |
| D6 | 0.50 × 年化波动率 + 0.50 × 60 日区间涨跌幅 |

任一子项缺失时按「已给权重归一」，全部缺失则该维度为 None。

## 三、综合股性分

```
composite = Σ_dim  weight[dim] × (100 − score[dim] if dim ∈ {d3} else score[dim]) / Σ weight
```

**六个维度必须全部可得才给综合分**；缺任何一维返回 None，由报告如实标注缺口，而不是把缺失当 0 拉低分数。

## 四、原型规则（固定优先级，首个命中即归类）

顺序本身是口径的一部分，不得重排：

| 顺序 | 原型 | 触发条件 |
|---|---|---|
| 1 | 连板妖股型 | `max_streak ≥ legend_streak`（与百分位无关，最稳） |
| 2 | 高波动题材型 | `d1 ≥ high` 且 `_elasticity ≥ elastic_high` 且 `d2 < mid` |
| 3 | 情绪活跃型 | `d1 ≥ high` 且 `d2 ≥ mid` 且（`d3` 缺失或 `d3 < high`） |
| 4 | 高埋人风险型 | `d3 ≥ high` 且 `d2 < low` |
| 5 | 趋势慢牛型 | `_trend ≥ trend_high` 且 `ret_60d_pct > 0` 且（`d1` 缺失或 `d1 < mid`） |
| 6 | 权重稳重型 | `d4 ≥ capacity_high` 且 `_elasticity < low` 且（`d1` 缺失或 `d1 < mid`） |
| 7 | 普通型 | 未命中以上任意一条 |

`_elasticity` 是波动率的池内百分位，`_trend` 是 60 日区间涨跌幅的池内百分位。

**普通型 = 「未获足够证据归类」**，不代表质地普通。缺证据（维度为 None）时不猜测，落到普通型。

### `legend_streak` 的标定（重要）

连板阈值必须**按窗口长度标定**，否则「连板妖股型」会吞掉大半个池子、使原型失去区分度。实测（301 只、12 个月窗口）：

| 阈值 | 命中占比 |
|---|---|
| ≥ 3 | 68% |
| ≥ 6 | 15% |
| ≥ 7 | 10% |

一键取数的默认值取 **6**（约前 15%）。注意该门槛**与板块无关**：ST 与北交所涨跌幅限制只有 5%，连板更容易，因此高连板样本会偏向 ST；解释「最高连板」时必须说明这一点。

## 五、象限与矩阵

- **象限**：以全样本 `d1`、`d2` 的**中位数**切分，`h/l + h/l` → `hh/hl/lh/ll`。任一分缺失不给象限。
- **板块×原型矩阵**：板块取池内只数前 12 个，其余合并为「其他行业」；单元格上行只数、下行该格平均综合分；`scored_count == 0` 的格子显示「—」而不是 0。
- **板块排序表**：按平均综合分降序；无任何可计分样本的板块显示「—」。

## 六、结构信号

`derive._signals` 只产出**结构描述**，不给方向、不给动作、不给价位：

- `quadrant_structure` — 象限分布与高异动样本占比
- `bury_concentration` — 高埋人风险型只数与集中的板块
- `negative_premium` — 高埋人风险型中次日平均为负的只数
- `legend_streak` — 窗口内最高连板
- `coverage` — 因证据不足未给综合分的只数
- `sector_ranking` — 板块平均股性分首位（池内相对排序，不是板块评级）

## 七、结论失效条件

- 换一个股票池，所有维度分必须重算（池内百分位只在本池内可比）。
- 换容量口径（成交额 ↔ 流通市值 ↔ 换手率），D4 的含义随之改变，原型归属可能变化。
- 窗口长度改变会改变「/年」折算与百分位排名。
- 除权日的涨跌幅失真会让该日的涨停被低估，进而影响异动计数。
