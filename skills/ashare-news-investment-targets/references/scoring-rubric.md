# 新闻投资标的评分细则

每个候选标的满分100分。评分不是为了制造确定性，而是为了把新闻机会拆成可比较的研究线索。

## 一、新闻强度，20分

| 分数 | 判断 |
| --- | --- |
| 0到5 | 普通新闻，缺少明确增量 |
| 5到10 | 行业关注度提升，但传导不够直接 |
| 10到15 | 明确利好或利空，能影响行业变量 |
| 15到20 | 政策、订单、价格、业绩、并购、供给冲击等强催化 |

加分信号：
- 有明确发布时间和可信来源。
- 是新信息，不是旧闻重复。
- 有财政资金、订单金额、价格数据、业绩数字或落地时间。

扣分信号：
- 只是观点、口号、展望。
- 标题很热但正文没有落地信息。
- 已被媒体和研报反复传播。

## 二、关联强度，20分

| 分数 | 判断 |
| --- | --- |
| 0到5 | 只是概念相关 |
| 5到10 | 产业链相关，但受益路径长 |
| 10到15 | 主营业务直接相关 |
| 15到20 | 收入、利润、订单或估值直接受益 |

优先给高分：
- 产品价格直接变化。
- 公司有明确产能或市场份额。
- 订单、客户、供应链关系可验证。
- 政策资金或招标能直接流向公司所在环节。

必须降分：
- 公司只是“有布局”“积极关注”“储备技术”。
- 相关业务收入占比很小。
- 只能通过多层间接传导才能受益。

## 三、预期差，15分

| 分数 | 判断 |
| --- | --- |
| 0到5 | 市场早已知道，股价已经充分反应 |
| 5到10 | 市场有部分预期 |
| 10到15 | 市场低估、误解或尚未充分反应 |

高分条件：
- 市场原本悲观，但数据开始改善。
- 公司市场标签可能改变。
- 新闻能验证此前未被认可的业务。
- 股价和研报关注度尚未明显反应。

低分条件：
- 板块已经连续高潮。
- 相关标的过去5到10天已经大涨。
- 利好公布后高开低走或放量滞涨。

## 四、业绩弹性，15分

| 分数 | 判断 |
| --- | --- |
| 0到5 | 难以影响业绩，只是情绪催化 |
| 5到10 | 可能影响订单或收入，但弹性待验证 |
| 10到15 | 对收入、成本、毛利率、订单或估值有明显弹性 |

重点看：
- 订单金额占去年营收比例。
- 订单金额占当前市值比例。
- 产品涨价能否传导到毛利。
- 产能是否足够。
- 成本是否稳定。
- 确认收入的时间是否在未来1到4个季度。

## 五、股价位置，10分

| 分数 | 判断 |
| --- | --- |
| 0到3 | 高位放量滞涨，追高风险大 |
| 3到6 | 普通跟涨，位置一般 |
| 6到8 | 低位放量、平台突破或趋势中继 |
| 8到10 | 低位加新闻催化，放量突破且承接良好 |

无法核验实时行情时，最多给中性分，并标记“待核验”。

## 六、板块强度，10分

| 分数 | 判断 |
| --- | --- |
| 0到3 | 板块不跟，只有个股异动 |
| 3到6 | 板块有反应但扩散弱 |
| 6到8 | 板块放量，多股跟涨 |
| 8到10 | 龙头强势，板块成交放大，形成梯队 |

重点看：
- 板块指数是否强于大盘。
- 龙头是否封板或趋势突破。
- 后排是否扩散。
- 板块成交额是否持续放大。

## 七、资金痕迹，10分

| 分数 | 判断 |
| --- | --- |
| 0到3 | 没有资金确认，或出现出货迹象 |
| 3到6 | 普通成交放大 |
| 6到8 | 有放量突破、回调缩量、机构调研等确认 |
| 8到10 | 新闻前提前异动，且板块共振、资金持续进入 |

可观察信号：
- 成交量和换手率。
- 分时承接。
- 龙虎榜。
- 融资余额。
- 北向或机构资金。
- 机构调研。
- 回购、增持、大宗交易。

## 八、一票否决和强制降级

出现以下情况，即使总分看起来高，也要降级：
- 公司与新闻只有名字或概念关系。
- 新闻已被充分交易，标的高位巨量滞涨。
- 关键数据无法核验，却需要依赖该数据才能成立。
- 存在明显减持、解禁、监管问询、业绩暴雷、退市风险。
- 新闻本身来源不清或疑似旧闻。
- 受益逻辑依赖违规、操纵或不可持续行为。

## 九、建议结论

| 总分 | 处理方式 |
| --- | --- |
| 80分以上 | 重点研究，可能进入交易池 |
| 65到80分 | 加入观察池，等待资金或数据确认 |
| 50到65分 | 只观察，不急，优先补证据 |
| 50分以下 | 暂时放弃 |

结论必须写成条件：
- 需要什么数据确认。
- 什么价格或资金行为说明市场认可。
- 什么情况说明逻辑证伪。
