# A股每日盘面复盘模板

```markdown
# A股每日盘面复盘｜YYYY-MM-DD

- 截止日期：
- 快照类型 / 修订 / 精确截止时间：
- 输入SHA-256：
- 覆盖：可得 / 部分 / 未知
- 结论属性：盘面证据与结构观察，不构成投资建议

## 连续历史

前一交易日、主要指标变化、20/60日分位、当前情绪状态连续天数；样本不足明确标注。

指标表默认五行（主要指数涨跌幅、上涨参与度、成交额、炸板率、涨停净差）。数据声明了延续性检验章节时，追加「昨日涨停池晋级率」一行，并把它作为可结算的验证点指标；没有该章节时该行不出现。

## 一、主要指数

指数收盘、涨跌幅、观察日和来源。

## 二、市场宽度

上涨/下跌/平盘、涨跌停、上涨占比和涨跌家数比。

## 三、短线情绪观察

炸板率、最高连板、预定义状态和触发规则。数据、股票池或口径不完整时明确输出unknown，不给仓位或交易指令。

声明了 `health_thresholds` 时追加「阈值体检」表：逐条列出条件、观察值、关系、阈值与成立与否，并注明只做条目枚举、不聚合成分数；缺观察值的条目列入未判定清单。

声明了 `streak_distribution` 时追加「连板梯队」表：逐档列出板数与家数，并给出首板/连板只数与首板占比。各档之和必须等于市场宽度的涨停家数。

声明了 `high_boards` 时追加「最高板质量」表：逐只列出高标的板数与已声明的质量证据（资金流/换手），并统计净流入为正/为负的只数；必须注明只作结构归因、不构成个股推荐。整列都缺证据的列不出现（不留整列 unknown）。

## 四、成交与流动性

当日成交额、较前值、较5日/20日均值以及覆盖口径。

## 五、板块表现

使用单一分类体系，列出实际覆盖样本和来源。板块带 `fund_flow` 时增加资金净流入列，并披露其 `method_category`。

板块项带 `leaders` 时追加「板块内重点个股」下钻表：只列输入显式声明的个股及其涨跌/资金流/换手，按资金流排序；必须注明这是板块归因、不构成个股推荐，且整列无值的列不出现。

`sectors` 带 `concept_view` 时追加「概念层资金流」两张表（净流入居前 / 净流出居前）：它是**第二套分类**，必须独立成表、不与行业层合并排序，并披露方法类别。概念与风格项（如「MSCI中国」「融资融券」「科技风格」）列在这里，不混入行业榜。

## 六、资金证据

每项写明数值、方法、观察日和来源；不把供应商“主力资金”推导写成客观事实。

## 七、风格结构

大小盘、成长价值、红利等相对指标及正负解释。

## 八、延续性检验：前一涨停池当日表现

对比区间、股票池（须与市场宽度同池）、池内只数、当日再涨停、晋级率与声明的健康线；可选池内平均与中位涨跌幅、昨日分组表现。未声明健康线时只给晋级率、不作高低判断。

## 九、双确认主线矩阵

显式声明象限规则（涨停家数阈值、板块资金阈值），列出每个主题的涨停家数、主题涨停股资金、声明板块资金求和、板块涨跌（等权）与象限；给出象限分布与读法。缺板块资金流的主题标 `unknown` 并列出缺口。明确写「结构分类，不是评分，不构成入场或仓位指令」。

可选声明 `quadrant_rules.bleeding_threshold_cny`（失血线）：声明后在规则句、象限分布与读法里追加「情绪失血」档，把「家数达标」按资金流出深度拆成情绪脉冲 / 情绪失血；未声明则该档不出现在计数、图例与信号中，输出与声明前逐字节一致。

## 十、事件与验证点

先展示上一期到期验证点的成立/未成立/无法判断及观察值，再列当日公开事件和结构化未来验证点。

## 十一、结构信号与限制

先列输入显式声明的反方证据与自我证伪，再列显式规则触发的背离与结构信号，最后列 partial/unknown 限制，不写投资指令。

## 十二、来源汇总

来源名称、URL和使用次数。
```
