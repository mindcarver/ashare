# A股每日盘面复盘模板

```markdown
# A股每日盘面复盘｜YYYY-MM-DD

- 截止日期：
- 输入SHA-256：
- 覆盖：可得 / 部分 / 未知
- 结论属性：盘面证据与结构观察，不构成投资建议

## 一、主要指数

指数收盘、涨跌幅、观察日和来源。

## 二、市场宽度

上涨/下跌/平盘、涨跌停、上涨占比和涨跌家数比。

## 三、成交与流动性

当日成交额、较前值、较5日/20日均值以及覆盖口径。

## 四、板块表现

使用单一分类体系，列出实际覆盖样本和来源。

## 五、资金证据

每项写明数值、方法、观察日和来源；不把供应商“主力资金”推导写成客观事实。

## 六、风格结构

大小盘、成长价值、红利等相对指标及正负解释。

## 七、事件与验证点

当日公开事件和已经公开日历中的未来验证点。

## 八、结构信号与限制

只列显式规则触发的背离以及partial/unknown限制，不写投资指令。

## 九、来源汇总

来源名称、URL和使用次数。
```
