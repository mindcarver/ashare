# 读者版深度与历史修订

适用于默认读者报告；输入、校验、派生和图表必须走技能入口。不要直接改生成后的 HTML 补结论。

## 先核对，再展开

出现报告分歧时，建立内部记录：双方值、定义、股票池、观察日、原始字段、计算式、取证时间、采用版本和未解决原因。参考报告不是事实来源。无法复现的数字不用于补齐覆盖。

- 量比固定为当日**成交量**÷此前五个交易日成交量均值，不含当日。成交额比单列；量比、成交量日环比、成交额日环比分别命名。
- 用 `scripts/price_volume.py::price_volume_metrics(rows, market_date)` 从带日期日线计算。不得将 `amount` 传作 `volume`。新采集的每个量价基准保存 `daily_bars` 和 `volume_basis: volume`；主输入校验会重算并拒绝标签与数据不符。历史输入缺日线仍兼容，但不声称已经复算。不足120日不计算120日分位。
- 收盘涨停池与收盘炸板未封池是互斥集合；成功封板池内曾开板的股票另算。封板率分母、家数与代码集合一起检查。
- 封单必须选定同一批快照。补充池与主输入金额冲突时拒用，不只验证成员数。若后续修订27只而其他字段不变，也不能自行称为盘中波动；确认不了原因就保留冲突。
- 1/3/5/10日资金为重叠累计窗口，不能相加。今日正、10日负是窗口分歧，不能在没有前日证据时写“今日转正”。

## 主线完整分析

正文每个主题说明：成员范围、当日结构、与前日变化、组内差异、已知事件、机制假设、反方证据、后续核验。至少把可得的板块资金、涨停、成员和相关事件组织在同一小节。

主输入主题可声明：

- `limit_up_codes`：精确去重的当日涨停代码，数量须等于 `limit_up.value`；读者补充池可得时还核对成员存在。
- `representative_board_id`：必须属于主题 `boards`。父子层级只选择这个明确的资金参照，不将父子相加。参照板块不等于主题整体；公开用“涨停与代表板块资金同向”，不能称已完成全主题去重。
- `public_scope`：安全公开的成员与参照范围说明。具体口径变更必须同步修改成员、家数和同成员资金合计，不能只改名称。

缺少代表板块/去重集合的多板块主题继续未知。不得为让主线表非空而凭名称猜测归属。主线排序复用声明的结构类别，无隐藏评分。

## 必须使用的已知数据

- 昨日池按昨日 `lbc=1` 与 `lbc>1` 分组，精确代码连接今日涨跌与资金；再涨停取两池交集。分别给只数、覆盖、均值、中位、资金、再涨停、未再涨停。
- 断板不等于收跌；20%股票涨12%不算涨停。缺行情/资金时分别给样本覆盖，部分资金之和不得称整个组资金。
- 展示高标首末封、盘中开板、封单与成交额的关系；封单为未成交委托，不是实成交资金。快照存在冲突时在本节说明，不能藏进附录。
- 分析当日与10日资金是否异号；完整1/3/5/10日表留在附录。
- 同组资金最高/最低成员和正/负/零成员数使用完整成分或明确样本。行业榜样本可成对比较，但不冒充全行业，更不能凭名字推断产业链环节。
- 龙虎榜买卖净额已披露而席位集中度未知时，深度组件为 `partial`，不能整节继续写“未知”。不得按席位编码字符串长度伪造席位数。
- 消息需回到公告或发布方核实；区分事件日、发布时间和本次取证时间。把事件与板块反应并列，不将同日新闻当作因果证明。补取只确认了产品发布，就不能复述未核实的订单、涨价或收入。

## 历史存档与时间边界

补充证券存档没有原采集时间时，不补造旧日时间。确需使用须声明 `retrieval_mode: historical_archive`、`original_fetched_at: null`、`publication_basis: known_by_fetch`，抓取时间为本次读取存档时刻；同时附 `quote_crosscheck`：独立、带同日时间戳的逐代码价格和涨跌记录。校验逐项比较 `f2/f3/f124`。这只能支持历史报价匹配，不能证明资金字段精确更新时间，正文必须保留限制。来源文件与哈希留内部。

`market_date` 是观察交易日，`snapshot.cutoff_at` 是当前修订可用信息截止。截止日期晚于交易日时标“历史修订版”，不得把补录新闻或后来结算伪装成收盘时已知。验证日已经过去而未接入同日证据时标“已到观察日，尚未结算”，不用“明日关注”。

## 阅读顺序和验收

正文：今日判断 → 主线逐条看 → 市场与延续性 → 后续核验。附录折叠保留全部证据表，避免六段机械复述同一指数表和首尾重复摘要。HTML仅一个主标题，有章节导航；表格只在自身容器横向滚动。

验收至少包括：量额方向相反、错日和缺目标日、封单批次冲突、前池部分覆盖与汇总冲突、断板但上涨、主题成员与代表板块引用、历史观察日期、部分龙虎榜、全未知输入、同输入重放；真实桌面和窄屏页面的导航、附录、表格与数据页搜索/排序。内部侧车保存逐组统计，正文、图表和数据页共用派生值。
