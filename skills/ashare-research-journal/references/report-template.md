# A股研究事后复盘 —— 报告结构

`show` 与 `stats` 生成自包含 HTML（由 `scripts/render.py` 组装，末尾注入 `_shared/` 设计令牌与页面外壳），
生成后用 `present_files` 交付。本文件是报告结构说明与人写部分的填空表，不是脚本模板。

## 单条复盘（`show`）

| 区块 | 内容 | 来源 |
|---|---|---|
| 记录标识与不可变性 | Research ID、标的、as_of、评价日、持有期标签、原快照 SHA-256、结果输入 SHA-256、记录时间 | 冻结快照，写入后不可覆盖 |
| 当时判断（冻结原文，未改写） | 研究假设、当时概率、成功标准、催化剂、证伪条件 | 逐字引用，扫描禁词不回改 |
| 当时证据 | 论断 / 取值 / 观察日 / 发布日 / 来源 | 快照 evidence |
| 到期结果 | 股票与基准价格路径图、股票收益、基准收益、超额、最大回撤、MFE/MAE、成功标准判定 | 结果输入，撤销基线后计算 |
| 判断审计 | 成功标准是否通过、是否触发证伪条件、最终 passed、已触发的证伪条件、结果输入备注 | 计算 + 人工归因 |

未写入结果时，「到期结果」只显示「尚未到期复核」，且**不生成**判断审计卡与价格路径图——
评价日前不产生任何评分。

## 统计看板（`stats`）

- 总体指标卡：成熟样本数、命中数、命中率、Brier 分数（附校准分母）、平均股票收益、平均超额、平均最大回撤。
- 图表：命中率仪表、超额分布柱状（**红=正超额、绿=负超额**，A 股口径）、Brier 校准散点（虚线为完美校准线）。
- 逐条明细表：Research ID / 标的 / 评价日 / 当时概率 / 股票收益 / 超额 / 最大回撤 / 判定。
- 必须同时阅读的限定：样本量、行业集中、市场阶段、选择偏差、命中率不等于赚钱。

没有成熟样本时只显示空态与口径说明，不画图、不编造数字。

## 人写部分：复盘归因（不属于自动报告）

以下内容由复盘人在正文中给出，自动报告只留提示位：

- 结果来自逻辑兑现、市场贝塔、风格，还是其他因素。
- 哪项证据最有预测价值 / 哪项假设缺少证据 / 哪个证伪信号本应更早观察。
- 下次可复用的流程改进。

不要从一次结果推出普遍规则；同时报告样本量和市场阶段。

## 报告性质声明

每份报告都带固定声明：**本报告为研究结论的事后复盘，引用文字来自当时冻结的研究记录、未作改写；
报告不构成投资建议，也不预测未来表现。** 这条声明替代禁词硬门禁（理由见 SKILL.md 第五节）。
