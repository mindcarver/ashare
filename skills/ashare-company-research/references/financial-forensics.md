# A股公司财务取证

执行完整报告、发现财务异常、比较同行或用户要求财务质量分析时读取本文件。目标是解释利润如何形成、现金是否兑现，以及哪些证据会推翻当前判断；不是给所有行业套同一组阈值。

## 一、先统一期间口径

财务报表中的收入、利润、现金流通常是累计流量，资产负债表是时点值。不得把累计季度直接相加。

单季度流量换算：

```text
Q1 = 一季报累计
Q2 = 半年报累计 - 一季报累计
Q3 = 三季报累计 - 半年报累计
Q4 = 年报累计 - 三季报累计
TTM = 最近四个互不重叠的单季度
```

同比必须使用同口径期间。出现会计政策变更、并购重组、终止经营、股本变化或追溯调整时，先说明可比性，再决定是否计算。

每个关键指标记录：`指标值 / 单位 / period_type / observed_at / published_at / fetched_at / source`。报告期末不是发布日期，不能用于点时回放的可得性判断。

## 二、利润和回报质量

### 利润率

```text
毛利率 = (营业收入 - 营业成本) / 营业收入
营业利润率 = 营业利润 / 营业收入
净利率 = 归母净利润 / 营业收入
```

拆解毛利率变化来自价格、产品结构、原材料、产能利用率、会计口径还是一次性因素。只看到毛利率上升，不能自动推断竞争力增强。

### ROE和杜邦

```text
ROE = 归母净利润 / 平均归母权益
ROA = 净利润 / 平均总资产
ROE ≈ 净利率 × 总资产周转率 × 权益乘数
```

平均余额优先用期初与期末平均。判断ROE由利润率、周转还是杠杆驱动；高ROE如果主要来自权益乘数上升，不能与经营改善等同。

### 资本回报

资本密集型公司可补充：

```text
ROIC = 税后经营利润 / 平均投入资本
投入资本 = 有息负债 + 股东权益 - 非经营性现金及资产
```

税率、非经营资产和有息负债口径必须公开，缺失时不制造ROIC。

## 三、现金转换与营运效率

```text
净现比 = 经营活动现金流净额 / 归母净利润
自由现金流 = 经营活动现金流净额 - 维持性资本开支
应收周转天数 = 平均应收项目 / 营业收入 × 期间天数
存货周转天数 = 平均存货 / 营业成本 × 期间天数
```

维持性资本开支通常无法从公开报表精确分离。无法区分维持性和扩张性资本开支时，标明使用总资本开支的限制，不把结果写成精确经济自由现金流。

重点比较：

- 营收增速与应收、合同资产、票据增速。
- 营业成本与存货、预付款、固定资产和在建工程。
- 净利润与经营现金流、现金收入、税费和分红。
- 订单、合同负债与未来收入确认的对应关系。

单年背离可能来自项目结算或季节性；连续期间背离、同行偏离和管理层解释共同决定风险权重。

## 四、偿债与流动性

非金融企业可使用：

```text
资产负债率 = 总负债 / 总资产
流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
利息覆盖倍数 = EBIT / 利息费用
净负债 = 有息负债 - 可用现金及现金等价物
```

同时检查短债、长期债、租赁负债、受限资金、担保、或有负债和债务到期结构。经营性负债与有息负债分开解释。

## 五、行业适用性

以下指标不能机械跨行业：

- 银行：不用普通企业资产负债率、流动比率或自由现金流判断安全，改看核心一级资本充足率、不良率、拨备覆盖率、净息差和贷款结构。
- 保险：关注偿付能力、综合成本率、投资收益和新业务价值；普通PE和经营现金流的解释有限。
- 券商：关注净资本、杠杆、经纪/投行/自营结构和市场敏感度。
- 地产与建筑：预收/合同负债、项目结算和高负债具有行业结构性，必须结合现金短债比、项目货值和回款。
- 周期与资源：峰值利润下低PE可能是周期顶部；使用中周期利润、成本曲线和商品价格情景。
- 研发型科技与创新药：亏损期PE无意义，关注现金跑道、研发费用化/资本化、里程碑、获批概率和稀释风险。

通用阈值只能作为提问起点，不能直接变成风险结论或评分。

## 六、财务与治理红旗

优先检查：

- 应收、合同资产或票据持续快于收入，回款天数恶化。
- 存货快于成本或收入，库龄恶化、跌价准备不足。
- 利润增长但经营现金流持续下降，或现金收入与收入长期背离。
- 毛利率显著偏离自身历史和可比同行，缺少业务解释。
- 研发资本化、在建工程转固、折旧年限、减值和收入确认发生激进变化。
- 非经常性损益、政府补助、资产处置或公允价值变动主导利润。
- 大额商誉、并购标的业绩承诺未达成、减值测试假设过于乐观。
- 关联交易、资金占用、违规担保、诉讼仲裁或受限资产异常。
- 审计意见非标准无保留、关键审计事项恶化、审计师或财务负责人频繁变更。
- 控股股东高质押、频繁减持、再融资和资本运作与经营恶化同时发生。

“应收增速超过收入1.5倍”等比例只用于触发复核。分母为负、接近零、基期异常或行业季节性明显时，不适用简单倍数。

## 七、输出要求

财务结论至少区分：

- `已验证事实`：数值、期间、来源。
- `机制解释`：变化由什么驱动。
- `异常假设`：可能的问题及替代解释。
- `验证路径`：下一份公告、现金回款、订单交付或同行数据如何验证。
- `证伪条件`：什么事实会推翻当前财务质量判断。

无法取得必要字段时写“不可计算”，不要使用行业均值、0或估算值填补。
