# A股公司估值政策

执行完整报告、估值比较、重估空间或情景推演时读取本文件。估值用于识别市场隐含预期和风险边界，不制造单一精确目标价。

## 一、先选择适用模型

| 方法 | 适用条件 | 禁用或降权条件 |
|---|---|---|
| PE / PEG | 盈利为正、会计口径稳定、同行可比 | 亏损、周期峰谷、一次性利润主导 |
| PB / ROE | 银行、保险或资产负债表驱动行业 | 轻资产、账面资产不能代表经济价值 |
| PS | 尚未盈利但收入口径稳定、商业模式可比 | 毛利率和单位经济性差异巨大 |
| EV/EBITDA | 资本结构差异大、折旧摊销显著 | 资本开支和营运资金需求巨大却被忽略 |
| DCF | 正常化自由现金流可解释且可预测 | 持续负现金流、周期剧烈、终值主导、关键参数无依据 |
| DDM | 分红稳定且分红政策能代表股东现金流 | 分红不稳定、资本约束或再投资需求剧烈变化 |
| SOTP | 多业务估值驱动不同 | 分部数据不足、内部交易无法消除 |
| 资产/清算价值 | 资产可变现、负债和或有责任清楚 | 资产质量、受限状态或处置成本不明 |

模型不适用时明确拒绝，不为了“估值完整”硬算。

## 二、同行样本契约

可比公司至少说明：

- 业务和利润来源是否相近。
- 客户、地区、成长阶段和周期位置是否相近。
- 会计政策、资本结构和股本稀释是否可比。
- 为什么纳入或排除异常公司。

不要只按概念板块或证券软件行业标签选同行。同行不足时用公司历史区间或分部估值，并降低结论置信度。

## 三、DCF最低要求

DCF输入必须可追溯：

- 基准自由现金流及其正常化过程。
- 收入、利润率、税率、资本开支和营运资金假设。
- 预测期、折现率和终值方法。
- 净负债、少数股东权益、非经营资产和潜在稀释。

```text
企业价值 = 预测期自由现金流现值 + 终值现值
股权价值 = 企业价值 - 净负债 - 少数股东权益 + 非经营资产
每股价值 = 股权价值 / 完全摊薄股数
```

季度现金流必须先转换为互不重叠期间；禁止把Q1、半年累计、前三季度累计和年报累计相加。终值占企业价值过高时，结论主要是参数假设而不是经营事实，必须显式提示。

## 四、DDM最低要求

使用稳定、可持续分红，不直接外推偶发特别股息。要求回报率必须大于永续增长率，并解释资本充足、再投资需求和分红政策是否允许该增长。

银行、保险等资本约束行业还需检查监管资本要求；不能只因为历史股息高就认定未来可持续。

## 五、相对估值与历史分位

- 历史分位只说明“相对过去的位置”，不能直接换算合理价格。
- 当前PE低可能来自盈利周期高点；当前PE高可能来自利润低谷。
- 先正常化利润或选择更适合的分母，再比较倍数。
- 港股、美股可比公司需解释会计、流动性、治理和市场风险溢价差异。

禁止使用“当前价格 × 50 / PE分位数”一类把百分位直接变成目标价的公式。

## 六、情景与敏感性

至少给悲观、中性、乐观三种情景，每种包含：

- 业务假设。
- 财务假设。
- 适用估值方法与倍数/参数。
- 触发条件和证伪条件。
- 对应市值或价格区间；数据质量不足时只给逻辑区间。

DCF至少展示折现率×增长率或折现率×利润率敏感性；相对估值至少展示盈利×估值倍数组合。不要只改变倍数而保持业务假设不变。

## 七、模型汇总

不同模型不能无条件算术平均。汇总时说明：

1. 哪个模型最适合主营业务。
2. 其他模型是交叉验证、上限、下限还是不可用。
3. 模型结果差异来自哪些假设。
4. 市场当前价格隐含了什么增长、利润率或资本回报。

数据覆盖、模型适用性或参数依据不足时，结论降级为“估值方向/隐含预期待核验”，不输出精确内在价值、买入价或安全边际。
